# NiwaShiba 🐔🐕

建築資材・商品の総合比較サイト。同じカテゴリーの商品を一括比較・情報収集できます。

## 構成

- `index.html` … ホーム（カテゴリー選択）
- `category/carport.html` … カーポート一覧・絞り込み
- `category/carport-detail.html` … 商品詳細
- `compare.html` … 商品比較表
- `data/carport.json` … 商品データ（追加・編集はここ）
- `images/carport/` … 商品画像（SVGフォールバック）
- `css/` `js/` … スタイル・スクリプト
- `data/README.md` … データ項目仕様
- `docs/アフィリエイト画像の入れ方.md` … 正規画像の掲載手順

## ローカルプレビュー

```bash
npx serve -l 3001 .
# http://localhost:3001/
```

## デザイン

黄緑×白を基調。マスコットは仲良しのニワトリ「ニワ」と芝犬「シバ」。
