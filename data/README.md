# 商品データ仕様（カーポート）

商品データは `data/carport.json` に格納します。
**商品を追加する時は `products` 配列にオブジェクトを1つ追加するだけ**です。HTMLは編集不要です。

---

> ## ⚙️ 現在の運用モード：Claude直接管理
>
> **`data/carport.json` が唯一のマスター**です。Claudeがこのファイルを直接編集します。
> オーナーは「画像リンク」と「アフィリエイトリンク」をClaudeに渡すだけ。Claudeが商品名・価格・
> スペックを調べて記入し、GitHubへ公開します。
>
> ⚠️ **`node tools/build-from-sheet.js` は実行しないこと**（Googleシート→JSONの上書き生成のため、
> 直接編集した内容が消えます）。スプレッドシート運用に戻す場合のみ使用。
> 現在のデータをCSVで見たいときは `node tools/export-to-csv.js`（読み取り専用の書き出し）。

---

## データ項目一覧

| キー | 意味 | 型 | 例 | 必須 |
|---|---|---|---|---|
| `id` | 商品の一意ID（重複NG） | 文字列 | `"lixil-carport-st-1"` | ◎ |
| `name` | 商品名 | 文字列 | `"カーポートST 1台用"` | ◎ |
| `maker` | メーカー名 | 文字列 | `"LIXIL"` | ◎ |
| `price` | 本体価格（税抜・円） | 数値 | `198000` | ◎ |
| `size_type` | 台数タイプ | 文字列 | `"1台用"` / `"2台用"` / `"3台用以上"` | ◎ |
| `width_mm` | 間口（幅）mm | 数値 | `2700` | ○ |
| `depth_mm` | 奥行 mm | 数値 | `5000` | ○ |
| `height_mm` | **全体の高さ**（地面〜屋根トップ）mm | 数値 | `2350` | ○ |
| `clearance_mm` | **有効高さ（桁下）**mm ※車の高さ制限に直結 | 数値 | `2050` | ○ |
| `roof_material` | 屋根材 | 文字列 | `"ポリカーボネート"` / `"折板"` | ○ |
| `roof_shape` | 屋根形状 | 文字列 | `"フラット"` / `"アール"` | ○ |
| `support_type` | 柱の支持方式 | 文字列 | `"片側支持"` / `"両側支持"` | ○ |
| `snow_resist_cm` | 耐積雪 cm | 数値 | `20` | ○ |
| `wind_resist_mps` | 耐風圧 m/s | 数値 | `38` | ○ |
| `heat_shield` | 熱線遮断機能の有無 | 真偽値 | `true` / `false` | ○ |
| `lighting` | 天井照明の有無 | 真偽値 | `true` / `false` | ○ |
| `color` | カラー | 文字列 | `"シャイングレー"` | ○ |
| `warranty_years` | メーカー保証年数 | 数値 | `2` | ○ |
| `image` | SVGフォールバック画像のパス | 文字列 | `"images/carport/xxx.svg"` | ○ |
| `url` | メーカー公式・参考URL | 文字列 | `"https://..."` | ○ |
| `image_real` | **正規ライセンス画像のURL**（提携先が発行）。設定すると `image` より優先表示 | 文字列 | `"https://thumbnail.image.rakuten.co.jp/..."` | △ |
| `image_credit` | 画像のクレジット表記（出典） | 文字列 | `"画像提供：楽天市場「○○エクステリア」"` | △ |
| `affiliate_provider` | アフィリ提供元 | 文字列 | `"楽天市場"` / `"Amazon"` | △ |
| `affiliate_url` | アフィリエイトリンク | 文字列 | `"https://hb.afl.rakuten.co.jp/..."` | △ |
| `rakuten_item_code` | **楽天の商品コード**（自動取得の元） | 文字列 | `"jyupro:car-csc-kj"` | △ |

> △ … アフィリエイト提携で正規画像を載せる場合に使用。空のままなら自動生成のSVGイラストが表示されます。

### ⭐ 自動取得（おすすめ）

`rakuten_item_code` を入れておけば、**価格・画像・アフィリリンクは手入力不要**です。
`node tools/refresh-rakuten.js` を実行すると、楽天APIから自動取得して `price` / `image_real` /
`affiliate_url` / `image_credit` を埋めてくれます（価格改定時も再実行するだけ）。
詳しくは [`docs/商品の管理方法.md`](../docs/商品の管理方法.md) を参照。

**商品コードの調べ方**：楽天の商品ページURL `item.rakuten.co.jp/<店舗>/<商品>/` の
`<店舗>` と `<商品>` を `:` でつなぐ。例 → `jyupro:car-csc-kj`

## 不明な値の扱い

値が分からない項目は **`null`**（数値・真偽値の場合）または **`""`（空文字）**（文字列の場合）にします。
→ 画面上では自動的に **「不明」** と表示されます。

```json
{
  "height_mm": null,
  "warranty_years": null,
  "url": ""
}
```

## 高さについて（重要）

カーポートの「高さ」は2種類あり、両方を記録します。

- `height_mm` … **全体の高さ**。地面から屋根の一番高い所まで。
- `clearance_mm` … **有効高さ（桁下高さ）**。地面から梁の下まで。**ここが車庫入れできる車高の上限**になるため、選定で最重要。

## 商品追加の手順

1. `data/carport.json` を開く
2. `products` 配列の末尾に `,` を付けて新しい `{ ... }` を追加
3. `id` が他と重複していないか確認
4. 保存してブラウザを再読み込み
