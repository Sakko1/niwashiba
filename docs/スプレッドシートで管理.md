# Googleスプレッドシートで商品を管理する

**あなたはスプレッドシートに行を足すだけ。Claudeがそれを読んでサイトを更新します。**

```
[あなた] Googleスプレッドシートに商品を追加・編集
                 ↓（ウェブに公開＝CSV）
[Claude] シートを読み込み → data/carport.json を生成 → GitHubへ公開
                 ↓
       NiwaShiba サイトに反映
```

---

## 🔰 最初の1回だけ：シートを用意する

### 1. スプレッドシートを作る
1. https://sheets.google.com/ で新規シート作成
2. **`data/products.csv` を取り込む**
   - Googleスプレッドシートで「ファイル → インポート → アップロード」
   - `data/products.csv` を選択 →「現在のシートを置換する」でインポート
   - → 9商品ぶんの行と、見出し（メーカー/商品名/価格…）が入った状態になります

### 2. ウェブに公開（CSV）する
1. メニュー「ファイル → 共有 → **ウェブに公開**」
2. 形式を **「カンマ区切り値（.csv）」** に変更
3. 「公開」 → 表示された**URLをコピー**
4. そのURLを **Claudeに渡す**（「これがシートのURLです」と貼るだけ）

> 公開されるのは商品情報（メーカー・価格・リンク等）だけで、**もともとサイトに載る公開情報**です。秘密ではありません。

## ✍️ 日々の運用：商品を追加・編集する

1. スプレッドシートに**1行 = 1商品**で記入（バリエーションも別行）
2. Claudeに「**シートを反映して**」と伝える
3. Claudeがシートを読み込み、サイトを更新・公開します

### 列の意味
| 列 | 必須 | 内容・記入例 |
|---|---|---|
| ID | - | 空でOK（自動採番）。手で付ける場合は他と重複しない英数字 |
| メーカー | ◎ | `LIXIL` / `YKK AP` / `三協アルミ` |
| 商品名 | ◎ | ユニークな商品名。例 `カーポートSC 1台用 LED照明付き` |
| タイプ | ○ | `1台用` / `2台用` / `3台用以上` |
| 間口mm / 奥行mm / 高さmm / 有効高さmm | ○ | 数値。例 `2700` |
| 屋根材 / 屋根形状 / 柱 | ○ | 例 `アルミ形材` / `フラット` / `片側支持` |
| 耐積雪cm / 耐風圧mps / 保証年 | ○ | 数値 |
| 熱線遮断 / 天井照明 | ○ | **`○` か `×`** で記入 |
| カラー | ○ | 例 `オフブラック` |
| 価格 | ○ | 税込価格の数値。例 `395000`（空なら「不明」表示） |
| 楽天商品コード | △ | 例 `jyupro:car-csc-kj`（楽天APIで自動更新したい場合） |
| 画像リンク | △ | 楽天等の**正規画像URL**。空ならイラスト自動生成 |
| アフィリエイトリンク | △ | 楽天等の**アフィリリンク**。入れると「楽天で見る」ボタンが出る |
| 公式URL | ○ | メーカー公式ページ |
| 画像クレジット | △ | 空でも自動で「画像・リンク提供：楽天市場」になります |

> **不明な値**は空欄でOK → サイトでは「不明」と表示されます。
> 真偽の列（熱線遮断・天井照明）は `○`/`×`、`あり`/`なし`、`TRUE`/`FALSE` のどれでも認識します。

## 🔁 仕組みの裏側（Claude用メモ）

- シートURLは `tools/sheet-source.txt` に保存（Git管理外）
- 反映コマンド：`node tools/build-from-sheet.js`
  - URL引数なしなら `sheet-source.txt`→無ければ `data/products.csv` を読む
- 楽天コードから価格/画像/リンクを自動取得：`node tools/refresh-rakuten.js`
- 公開：`git add -A && git commit -m "商品更新" && git push`

## ❓ よくある質問

**Q. スマホからでも追加できる？**
A. はい。Googleスプレッドシートアプリで行を足し、Claudeに「反映して」と言うだけです。

**Q. 楽天の価格が変わったら？**
A. 価格列を直して「反映して」と言うか、楽天商品コードを入れておけば自動取得もできます。

**Q. 画像リンクとアフィリリンクはどこで取る？**
A. 楽天アフィリエイトの「商品リンク」作成画面で取得できます。
   詳しくは `docs/アフィリエイト画像の入れ方.md`。
