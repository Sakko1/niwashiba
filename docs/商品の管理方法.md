# 商品の管理方法（かんたん運用ガイド）

このサイトは **「楽天の商品コードを登録 → コマンド1つで自動取得」** で運用できます。
価格・画像・アフィリエイトリンクは手入力せず、**楽天APIから自動で取得**します。

---

## 🔰 最初の1回だけ：楽天APIの準備

1. **楽天アプリIDを発行**（無料）
   https://webservice.rakuten.co.jp/ → 「アプリID発行」
2. **設定ファイルを作る**
   `tools/rakuten-config.example.json` をコピーして `tools/rakuten-config.json` を作成
3. 中身を自分のIDに書き換える
   ```json
   {
     "applicationId": "発行された楽天アプリID",
     "affiliateId": "あなたの楽天アフィリエイトID"
   }
   ```
   > このファイルはGit管理外（公開されません）。安全です。

---

## ➕ 商品を追加する（バリエーションも別商品として）

カーポートSCの「サイズ違い」「照明付き」なども、**1つずつ別商品として登録**します。

### 手順
1. 楽天で対象商品を開き、URLから**商品コード**を作る
   `item.rakuten.co.jp/jyupro/car-csc-led/` → **`jyupro:car-csc-led`**
2. `data/carport.json` の `products` に、下のテンプレートを1つ追加
3. **スペック**（サイズ・照明など、楽天では分からない項目）を手で記入
4. ターミナルで自動取得を実行
   ```bash
   node tools/refresh-rakuten.js
   ```
   → 価格・画像・リンクが自動で入る
5. 公開
   ```bash
   git add -A && git commit -m "商品追加" && git push
   ```

### 商品テンプレート（コピーして使う）
```json
{
  "id": "lixil-carport-sc-led-1",
  "name": "カーポートSC 1台用 LED照明付き",
  "maker": "LIXIL",
  "size_type": "1台用",
  "width_mm": 2700,
  "depth_mm": 5754,
  "height_mm": 2350,
  "clearance_mm": 2100,
  "roof_material": "アルミ形材",
  "roof_shape": "フラット",
  "support_type": "片側支持",
  "snow_resist_cm": 20,
  "wind_resist_mps": 42,
  "heat_shield": false,
  "lighting": true,
  "color": "オフブラック",
  "warranty_years": 2,
  "url": "https://www.lixil.co.jp/",
  "rakuten_item_code": "jyupro:car-csc-led",

  "price": null,
  "image": "",
  "image_real": "",
  "image_credit": "",
  "affiliate_provider": "",
  "affiliate_url": ""
}
```
> 下の6項目（price〜affiliate_url）は**空でOK**。`refresh-rakuten.js` が自動で埋めます。
> `id` は他と重複しない一意な文字列にしてください。

## 🔄 価格を最新にする（定期メンテ）

楽天の価格は変動します。たまに以下を実行するだけで全商品の価格・画像が最新になります。
```bash
node tools/refresh-rakuten.js
git add -A && git commit -m "価格更新" && git push
```

---

## 📐 SVGイラストに戻したい / 楽天画像が無い商品

`rakuten_item_code` と `image_real` を空にすれば、自動生成のSVGイラスト（`image`）が表示されます。
SVGを作り直す場合は `node tools/gen-carport-images.js`。

## ❓ よくある質問

**Q. 楽天以外（Amazon・A8・もしも）も使える？**
A. 仕組みは楽天API前提です。Amazon等は手動で `image_real` / `affiliate_url` / `image_credit` を
記入すれば同様に表示できます（自動取得は楽天のみ）。

**Q. スペック（サイズ・照明）は自動で取れる？**
A. 取れません。サイズや照明の有無は商品により表記がバラバラなため、**手入力**してください。
分からない値は `null`（数値）や `""`（文字列）にすると画面で「不明」と表示されます。

**Q. 値段を載せず「楽天で確認」にしたい**
A. `price` を `null` にすれば「価格不明」と表示されます（運用方針に応じて選べます）。
