# 新しいカテゴリーの追加方法（汎用構造）

サイトは**カテゴリー非依存の汎用エンジン**になっています。
キッチン・お風呂などを追加するには、主に **①設定を1ブロック足す ②データを用意 ③HTMLを2枚置く** だけです。

## 仕組み（共通エンジン）
- `js/categories.js` … カテゴリー定義レジストリ（`CATEGORIES`）＋共通ヘルパー
- `js/catalog.js` … 一覧＋絞り込み（**フィルタUIは設定から自動生成**）
- `js/detail.js` … 商品詳細（サイズ別バリエーション対応）
- `js/compare.js` … 比較表（範囲表示対応）
- 各HTMLは `window.NIWA_CATEGORY='xxx'` で対象カテゴリーを指定

---

## 手順

### ① `js/categories.js` の `CATEGORIES` に定義を追加
カーポートの定義をコピーして、項目（`fields`）・絞り込み（`filters`）・カードに出す項目
（`cardSpecs`）・比較の最良値（`bestValue`）などをカテゴリーに合わせて書き換える。

```js
kitchen: {
  id: 'kitchen', label: 'キッチン', emoji: '🍳',
  dataPath: 'kitchen.json',
  storageKey: 'niwashiba_compare_kitchen',
  listPage: 'kitchen.html', detailPage: 'kitchen-detail.html',
  lead: 'メーカー・価格・間口・タイプなどで比較できます。',
  fields: [
    { key:'maker', label:'メーカー' },
    { key:'price', label:'価格（税込）', format:v=>'¥'+Number(v).toLocaleString() },
    { key:'width_mm', label:'間口', format:v=>v+' mm' },
    { key:'counter', label:'ワークトップ' },
    // …キッチン固有の項目…
  ],
  cardSpecs: ['price','width_mm','counter'],
  highlights: ['width_mm','counter','maker'],
  rangeKeys: ['price','width_mm'],
  sizeOrder: [],
  bestValue: { minBetter:['price'], maxBetter:[] },
  filters: [
    { key:'maker', label:'メーカー', type:'list' },
    { key:'price', label:'価格帯', type:'range', ranges:[['0-300000','〜30万円'], …] },
    { key:'counter', label:'ワークトップ', type:'list' },
    { key:'features', label:'機能', type:'bool', items:[{key:'dishwasher',label:'食洗機付き'}] },
  ],
  sorts: [
    { value:'default', label:'おすすめ順' },
    { value:'price-asc', label:'価格が安い順', num:'price', dir:1 },
  ],
},
```

### ② データを `data/kitchen.json` で用意
カーポートと同じ形式（`{ category, products:[…] }`）。商品オブジェクトのキーは
`fields` の `key` に合わせる。バリエーション（サイズ別）も同じ `variants` 形式で対応。

### ③ HTMLを2枚用意
`category/carport.html` と `carport-detail.html` をコピーして
`kitchen.html` / `kitchen-detail.html` を作成。違いは末尾のこの1行だけ：

```html
<script>window.NIWA_CATEGORY = 'kitchen';</script>
```

絞り込みサイドバー（`<aside class="filters" id="filters"></aside>`）と
並び替え（`<select id="sortSelect"></select>`）は**空のままでOK**（JSが設定から生成）。

### ④ トップページのカテゴリーカードを「公開中」に
`index.html` の該当カテゴリーカードを、Coming Soon の `<div>` から
`<a href="category/kitchen.html">` のリンクに変更。

---

## 楽天データの自動取得
カーポートと同じ仕組み（`tools/build-variant-models.js` / `refresh-rakuten.js`）を
カテゴリー別に流用できます。検索キーワードやサイズ抽出はカテゴリーに合わせて調整します。

## 注意（現状の制限）
- 比較ページ `compare.html` は現在 `NIWA_CATEGORY='carport'` 固定です。
  複数カテゴリーで比較を分けるなら、カテゴリー別の compare ページ or `?category=` 対応を追加します。
